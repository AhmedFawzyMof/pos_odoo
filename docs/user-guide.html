نظام نقاط البيع المخصص

نظرة عامة على النظام

هذا النظام هو واجهة أمامية مخصصة (Frontend) مبنية باستخدام Nuxt 3 + Vue 3 + Nitro تتصل بخادم Odoo عبر واجهة XML-RPC. يهدف النظام إلى توفير تجربة بيع سريعة ومبسطة تناسب المتاجر والمطاعم الصغيرة مع دعم كامل للغة العربية واختصارات لوحة المفاتيح.

الهدف

توفير واجهة بيع سريعة وعربية بالكامل مع تحسين سرعة إتمام عمليات البيع اليومية لتتناسب مع احتياجات السوق المحلي.

النطاق

نقاط البيع بالتجزئة، المطاعم الصغيرة، والمتاجر التي تحتاج نظام بيع سريع مع إدارة مخزون ومحاسبة مبسطة.

الجمهور

الكاشيرات، مديري المتاجر، المحاسبين، وأصحاب المتاجر الصغيرة والمتوسطة الذين يحتاجون نظام نقاط بيع عربي سهل الاستخدام.

مقارنة التدفق: Odoo القياسي مقابل التدفق المخصص

Odoo القياسي

التدفق التقليدي داخل Odoo (الواجهة الأصلية)

1

تهيئة نقطة البيع (pos.config)

تكوين الكاشير، وسائل الدفع، الضرائب، الطابعات، الشاشات المساعدة.

2

فتح الجلسة (pos.session)

فتح النقدية الأولية، إنشاء القيود المحاسبية، تخصيص المخزون للجلسة.

3

إنشاء الطلبات (pos.order)

إضافة منتجات، خصومات، اختيار عميل، دفع، طباعة إيصال.

4

إغلاق الجلسة والتسوية

عد النقدية، حساب الفروق، إنشاء التقارير المالية للجلسة.

5

التقارير والمحاسبة

تقارير المبيعات، حساب الأرباح والخسائر، المخزون، القيود المحاسبية.

النظام المخصص

التدفق المبسط في الواجهة المخصصة

1

تسجيل الدخول واختيار نقطة البيع

تسجيل الدخول، اختيار الكاشير، إدخال النقدية الافتتاحية، التوجيه إلى /cashier.

2

شاشة الكاشير — البيع السريع

شبكة منتجات، بحث، ماسح باركود، تصفية بالفئات، سلة مشتريات سريعة.

3

إتمام الدفع — اختصارات لوحة المفاتيح

F1 نقداً، F2 بطاقة، F3 خصم، F4 عميل، F5 تعليق، F12 إغلاق، أسهم التنقل، +/- كمية.

4

إدارة الجلسة — الخزنة والإغلاق

إيداع وسحب من الخزنة، إغلاق الجلسة مع عد النقدية والتسوية.

5

المتابعة الإدارية — صفحات متخصصة

المنتجات، العملاء، الموردين، المشتريات، المخزون، المحاسبة، التقارير.

متى يبقى Odoo القياسي أفضل؟

  • المحاسبة المعقدة — قيود محاسبية يدوية متعددة العملات
  • CRM وإدارة علاقات العملاء المتقدمة
  • التصنيع وإدارة الإنتاج وجدولة الموارد
  • التقارير المالية المتقدمة والموحدة
  • إدارة الموارد البشرية والرواتب

متى يكون النظام المخصص أفضل؟

  • المتاجر الصغيرة والمتوسطة — تحتاج واجهة بيع بسيطة وسريعة
  • الواجهة العربية أولاً — دعم كامل للغة العربية والاتجاه RTL
  • سرعة البيع — اختصارات لوحة المفاتيح تزيد سرعة الكاشير 3x
  • مخزون بسيط — لا حاجة لإدارة مستودعات معقدة
  • نشر سريع — منصة Nuxt SPA خفيفة وسريعة التحميل

شاشة الكاشير

نقاط البيع

الواجهة الأهم — شاشة البيع السريع مع دعم الباركود واختصارات لوحة المفاتيح.

وصف مفصل

  • شاشة البيع الأساسية المصممة للسرعة والكفاءة في إتمام عمليات البيع.
  • تدعم إضافة المنتجات عبر البحث أو الماسح الضوئي للباركود مع فلترة بالفئات.
  • توفر اختصارات لوحة مفاتيح شاملة لتنفيذ جميع الإجراءات دون لمس الفأرة.
  • تتكامل مع الخزنة لإدارة النقد والجلسة وإغلاقها في نهاية اليوم.

اختصارات لوحة المفاتيح

  • F1 — الدفع نقداً
  • F2 — الدفع ببطاقة
  • F3 — إضافة خصم
  • F4 — تحديد عميل
  • F5 — تعليق الطلب (Park)
  • F6 — فتح الخزنة
  • F7 — إيداع خزنة
  • F8 — سحب خزنة
  • F9 — طباعة الإيصال
  • F10 — فتح السجل النقدي
  • F11 — ملء الشاشة
  • F12 — إغلاق الجلسة
  • ↑ ↓ — التنقل بين المنتجات
  • + - — زيادة/تقليل الكمية
  • Enter — إضافة المنتج للسلة
  • Delete — حذف عنصر من السلة
  • Esc — إلغاء العملية الحالية

البيانات المعروضة

  • شبكة المنتجات مع الصور والأسعار
  • شريط البحث مع دعم الباركود
  • قائمة الفئات الجانبية
  • سلة المشتريات مع تفاصيل الكميات
  • إجمالي الفاتورة والضريبة
  • معلومات الجلسة والنقدية الحالية
  • اختصارات لوحة المفاتيح المتاحة

الإجراءات المتاحة

  • البحث عن المنتجات بالنص أو الباركود
  • تصفية المنتجات حسب الفئات
  • إضافة منتجات للسلة بالنقر أو بالباركود
  • تعديل كميات المنتجات (بالماوس أو لوحة المفاتيح)
  • تحديد طريقة الدفع (نقدي F1 / بطاقة F2)
  • إضافة خصم على الفاتورة (F3)
  • تحديد العميل (F4)
  • تعليق الطلب وإعادته لاحقاً (F5)
  • إدارة الخزنة (إيداع F7 / سحب F8)
  • طباعة الإيصال (F9)
  • إغلاق الجلسة مع التسوية (F12)

حالات الاستخدام

  • بيع سريع: مسح باركود المنتجات واختيار الدفع → يتم في ثوانٍ
  • بيع مع خصم: إضافة منتجات، ضغط F3، إدخال نسبة الخصم
  • بيع لعميل محدد: ضغط F4، اختيار العميل، إتمام البيع
  • منتجات وزنية: إضافة المنتج، استخدام +/- لتحديد الوزن
